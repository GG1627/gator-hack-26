# Phase 6 replay design

Reference: `phase6-concept.png` (AI-generated interface concept; its illustrative cells are never used as scientific imagery).

Local artifact viewer in React/Vite/TypeScript; no server computation or controller execution. This is the smallest static implementation of the suggested web architecture.

Near-black navy #0a1014 background, #edf2f5 text, #a9b5bf muted text, #344149 borders, #c5f277 PHOTON accent. System sans for reading, monospace for instruments/numbers. Thin rectangular media frames, restrained 6px control radius, 24px section gaps. Large comparative images form the focal point. No image tint, synthetic nuclei, decorative glow, or fabricated scale bars.

Components: app/load/error shell, experiment controls, comparison viewers, shared transport, exposure timelines, decision inspector, evaluation reveal, metric table, provenance/research disclosure. Images retain square aspect; paired desktop columns stack on mobile. Controls have visible focus and labels. Playback uses discrete source steps and respects user pause/scrub; reduced motion disables transitions.

Required content corrections to the concept: actual C. elegans embryos rather than its invented zebrafish dropdown; authentic 3D maximum-intensity projections; held measurements explicitly identified; predictions are the actual saved causal Gaussian scenes; retrospective event counts and metrics hidden until evaluation reveal. No claims of event-prediction validity or biological benefit. Exposure savings are relative to imaging every source volume; fixed and PHOTON have equal budgets. Current fixed-event-coverage wins remain visible.
